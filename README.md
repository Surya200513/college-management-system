# college-management-system
The College Management System is a Power BI analytics project built on a dataset of 1,500 student records across 10 undergraduate departments (such as BBA, B.Sc Computer Science, BCA, B.Sc Mathematics, B.Sc Physics, B.A Tamil, B.A English, B.Sc Chemistry, B.Com, and B.Com CA) and three academic years (First Year, Second Year, and Third Year). Using a multi-page interactive Power BI report (10 pages featuring KPI cards, slicers, action buttons, and column, pie, and donut charts), the dashboard helps track student demographics, admission channels (Counselling vs. Management), residential status (Day Scholar vs. Hosteller), daily attendance (Present vs. Absent), academic performance (CGPA), and arrear status.
